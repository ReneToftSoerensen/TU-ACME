# UC-10.03 — Import to Windows store calls Import-PfxCertificate

**Behavior:** When the operator selects "Import to Windows certificate store (LocalMachine\My)", the menu resolves the chosen certificate via `Get-PACertificate -MainDomain <subject>` and calls `Import-PfxCertificate -FilePath $cert.PfxFile -CertStoreLocation 'Cert:\LocalMachine\My' -Password (ConvertTo-SecureString $cert.PfxPass -AsPlainText -Force)` exactly once. Event 1011 is emitted on success.

**Given** the export menu is open with at least one prod certificate listed
**When** the operator picks a cert and selects "Import to Windows certificate store"
**Then** `Import-PfxCertificate` is called once with `-CertStoreLocation 'Cert:\LocalMachine\My'` and `Write-EventLogEntry` emits Event 1011

**Implementation:** `TU-ACME/Private/Export/Invoke-ExportMenu.ps1`
**Test:** `tests/Unit/Export/UC-10.03.Tests.ps1`
