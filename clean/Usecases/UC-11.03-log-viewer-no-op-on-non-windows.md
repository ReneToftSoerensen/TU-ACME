# UC-11.03 — Log viewer is a no-op on non-Windows

**Behavior:** On non-Windows runtimes the Windows Event Log is unavailable, so the viewer prints a yellow advisory and returns immediately without calling `Get-WinEvent`.

**Given** the module is running with `$script:OnWindows = $false`
**When** `Invoke-LogViewer` is called
**Then** `Get-WinEvent` is NOT called, a yellow "Event Log viewing not supported on this platform" message is printed, and the function returns

**Implementation:** `TU-ACME/Private/Logs/Invoke-LogViewer.ps1`
**Test:** `tests/Unit/Logs/UC-11.03.Tests.ps1`
