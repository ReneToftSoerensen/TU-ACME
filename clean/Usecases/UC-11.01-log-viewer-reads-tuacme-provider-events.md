# UC-11.01 — Log viewer reads TU-ACME provider events

**Behavior:** Opening the log viewer queries the Windows Application log filtered to the `TU-ACME` provider and renders the most recent 50 events.

**Given** the module is running on Windows (`$script:OnWindows = $true`) and the Application log contains TU-ACME provider events
**When** `Invoke-LogViewer` runs
**Then** `Get-WinEvent` is called exactly once with `-LogName Application`, `-FilterHashtable @{ ProviderName = 'TU-ACME' }`, and `-MaxEvents 50`, and the resulting rows are passed to `Show-Table`

**Implementation:** `TU-ACME/Private/Logs/Invoke-LogViewer.ps1`
**Test:** `tests/Unit/Logs/UC-11.01.Tests.ps1`
