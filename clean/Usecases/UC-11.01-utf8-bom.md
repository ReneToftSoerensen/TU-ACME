# UC-11.01: UTF-8 BOM File Encoding

## Narrative

As a **code maintainer**, I want to **ensure all PowerShell files have UTF-8 BOM encoding**, so that **both Windows PowerShell 5.1 and PowerShell 7+ parse non-ASCII characters correctly**.

## Acceptance Criteria

- [ ] All `*.ps1` files have first three bytes `EF BB BF` (UTF-8 BOM)
- [ ] All `*.psm1` files have UTF-8 BOM
- [ ] All `*.psd1` files have UTF-8 BOM
- [ ] The `verify-utf8-bom` skill detects missing BOMs
- [ ] Pre-commit hook or CI check prevents BOM-less files from being merged
- [ ] Markdown files (`.md`) do not require BOM

## Implementation Notes

- Skill: `verify-utf8-bom` (`.claude/skills/verify-utf8-bom.ps1`)
- Agent: `ps51-compat-linter` (checks on every diff)
- Editor must save as UTF-8 with BOM (VS Code: "UTF-8 with BOM" encoding)
