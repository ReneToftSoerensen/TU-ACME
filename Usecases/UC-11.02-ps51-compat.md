# UC-11.02: PowerShell 5.1 Compatibility

## Narrative

As a **code maintainer**, I want to **ensure all code is compatible with Windows PowerShell 5.1**, so that **TU-ACME runs on both PS 5.1 and PS 7+ without modification**.

## Acceptance Criteria

- [ ] No PS7-only syntax is used (no `??`, `?.`, `?[`, `using namespace`, etc.)
- [ ] All code parses cleanly on PS 5.1 runtime
- [ ] No PowerShell 7-exclusive cmdlets are used without PS 5.1 fallbacks
- [ ] The `ps51-compat-linter` agent detects PS 5.1 incompatibilities
- [ ] Pre-commit hook prevents PS7-only syntax from being merged
- [ ] Test suite runs on both PS 5.1 and PS 7+ (CI matrix)

## Banned Syntax (PS 7-only)

- Null-coalescing operator: `??`
- Null-conditional operators: `?.`, `?[`
- Ternary operator: `a ? b : c`
- Top-level pipeline chains: `cmd1 && cmd2 || cmd3`
- `using namespace` statement
- `ConvertFrom-Json -AsHashtable`
- `ForEach-Object -Parallel`
- Null-safe indexing: `$obj?[0]`

## Implementation Notes

- Agent: `ps51-compat-linter` (checks on every diff)
- Use PS 5.1-compatible idioms (e.g., `if ($x -eq $null)` instead of `if (!$x)`)

## Test Coverage

**Unit:** Run on PS 5.1 runtime; verify all tests pass.

**Integration:** Run on PS 5.1 runtime; verify integration tests pass.

**Scripts:** Run on PS 5.1 runtime; verify scripts execute.
