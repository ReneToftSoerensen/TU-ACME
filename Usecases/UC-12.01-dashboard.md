# UC-12.01: Certificate Dashboard

## Narrative

As an **operator**, I want to **view all certificates with their domain, expiry, thumbprint, and IIS bindings**, so that **I can see the state of all certificates and plan maintenance**.

## Acceptance Criteria

- [x] Dashboard displays a table of all certificates in the prod store
- [x] Columns: Domain, Expiry Date, Thumbprint, IIS Binding(s)
- [x] Certificates are sorted by expiry date (soonest first)
- [x] Certificates within 30 days of expiry are highlighted or marked as "Renew Soon"
- [x] Expired certificates are clearly marked
- [x] Dashboard is keyboard-navigable (up/down to scroll)
- [x] Dashboard shows count of total, valid, and expiring-soon certificates
- [ ] Dashboard allows filtering by domain (optional)
- [x] Dashboard is read-only (no edit in this view)

## Implementation Notes

- Function: Dashboard helper in `Private/Certificates/`
- Displayed via menu → dashboard option
- Data comes from Posh-ACME store and IIS bindings

## Test Coverage

**Unit:** Mock cert and IIS data; verify formatting and sorting.

**Integration:** Load real certs from store; verify dashboard display.
