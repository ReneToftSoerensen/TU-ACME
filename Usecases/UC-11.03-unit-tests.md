# UC-11.03: Unit Test Suite

## Narrative

As a **developer**, I want to **run unit tests that mock external dependencies**, so that **I can verify module functions in isolation without touching the file system or Posh-ACME store**.

## Acceptance Criteria

- [x] Unit tests are tagged with `-Tag Unit` in Pester
- [x] Unit tests mock Posh-ACME cmdlets (`New-PAAccount`, `Set-PAServer`, etc.)
- [x] Unit tests mock file I/O (config.json read/write)
- [x] Unit tests mock Windows Event Log operations
- [x] Unit tests run in < 10 seconds
- [x] `Invoke-Pester -Tag Unit` executes all unit tests
- [x] All unit tests pass with green status
- [x] New functions have corresponding unit tests

## Implementation Notes

- Mocking via Pester's `Mock` and `InModuleScope`
