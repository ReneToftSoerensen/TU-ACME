# UC-10.01: Configuration Persistence

## Narrative

As an **operator**, I want to **have configuration persist across module reloads and reboots**, so that **TU-ACME is always ready to operate without re-running the first-run wizard**.

## Acceptance Criteria

- [x] Configuration is stored in `%ProgramData%\TU-ACME\config.json`
- [x] Config includes: prod URL, prod account ID, staging URL, staging account ID, contact email
- [x] Config is readable on module import
- [x] Config is validated (no missing required fields)
- [x] On reimport, no first-run wizard is triggered if config exists
- [x] On reimport, all configuration is loaded and available to functions

## Implementation Notes

- Config format: JSON (plaintext)
- Stored location: `%ProgramData%\TU-ACME\config.json`
- Accessed via `Get-TUACMEConfig` helper function

## Test Coverage

**Unit:** Mock file I/O; verify config parsing and validation.

**Integration:** Write config, reimport module, verify config is loaded.
