# UC-12.02: Renewal Status Report

## Narrative

As an **operator**, I want to **view the renewal status of all certificates**, so that **I can see which certificates were recently renewed and which are overdue for renewal**.

## Acceptance Criteria

- [ ] Renewal status report displays all certificates with renewal-related metadata
- [ ] Columns: Domain, Expiry Date, Days Remaining, Last Renewal Date, Next Renewal (estimated)
- [ ] Certificates are sorted by days remaining (fewest first)
- [ ] Certificates overdue for renewal (< 0 days) are highlighted
- [ ] The report includes a summary: total certs, currently valid, overdue, renewed-last-24h
- [ ] Report is read-only and keyboard-navigable
- [ ] Report refreshes on-demand (no auto-refresh)

## Implementation Notes

- Function: Renewal status helper in `Private/Certificates/`
- Displayed via menu → renewal status option
- Metadata comes from Posh-ACME store (renewal dates, order history)
- Estimation: next renewal = expiry - 30 days

**Integration:** Load real certs; verify status display.
