# UC-10.02: SMTP Credential Encryption

## Narrative

As a **security-conscious operator**, I want to **store the SMTP password encrypted**, so that **credentials are not readable in plaintext from the config file**.

## Acceptance Criteria

- [ ] SMTP password prompt uses `Read-Host -AsSecureString`
- [ ] Password is converted to DPAPI-encrypted string via `ConvertFrom-SecureString` (no key)
- [ ] Encrypted password is stored in `config.json` alongside plaintext server/port/username
- [ ] On config load, encrypted password is decrypted via `ConvertTo-SecureString`
- [ ] Decrypted password is used for SMTP operations
- [ ] DPAPI encryption is per-machine (cannot be transferred between machines)

## Implementation Notes

- SMTP config stored in config.json with both plaintext and encrypted fields
- DPAPI uses machine-level encryption
- Passwords never logged to Event Log

## Test Coverage

**Unit:** Mock `ConvertFrom-SecureString` and `ConvertTo-SecureString`; verify encrypt/decrypt flow.

**Integration:** Configure SMTP, verify password is encrypted in config file.
